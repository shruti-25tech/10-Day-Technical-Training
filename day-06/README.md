\# Day 6 — TypeScript + React



\## Objective



Learn TypeScript fundamentals and build a component-based React Employee Management Dashboard using TypeScript.



\## Technologies Used



\* TypeScript

\* React

\* Vite

\* HTML/CSS

\* JavaScript/TypeScript

\* DummyJSON API



\## TypeScript



Covered:



\* Primitive types

\* Arrays and objects

\* Interfaces

\* Type aliases

\* Union types

\* Enums

\* Optional properties

\* Functions

\* Classes

\* Generics

\* Type narrowing and type guards



\## React Employee Management Dashboard



Features:



\* Total employees

\* Average salary

\* Department count

\* Employee list

\* Search employees

\* Filter by department

\* Sort by name or salary

\* View employee details

\* Add employee

\* Edit employee

\* Delete employee

\* Form validation

\* API integration

\* Loading and error handling

\* Reusable React components

\* Custom `useEmployees` hook

\## API



Employee data is fetched from the DummyJSON Users API.



The API does not provide salary information, so salary values are generated for demonstration purposes.



\## Run React Application



```bash

cd react-app

npm install

npm run dev

```



The application can then be opened in the local Vite development server.



\## Build Check



The React application was successfully verified using:



```bash

npm run build

```
