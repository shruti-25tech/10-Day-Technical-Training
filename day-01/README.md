# Day 01 - Employee Management CLI

## Project Description

Employee Management CLI is a Python-based command-line application for managing employee records.

The application allows users to add, update, delete, search and display employee information. It also provides salary-related operations and department filtering.

## Features

- Add Employee
- Update Employee
- Delete Employee
- Search Employee
- List All Employees
- Find Highest Salary
- Calculate Average Salary
- Filter Employees by Department

## Technologies Used

- Python 3
- Command Line Interface (CLI)

## Python Concepts Used

- Variables
- Lists
- Dictionaries
- Functions
- Conditional Statements
- Loops
- Exception Handling
- List Comprehension
- Built-in Functions such as `max()` and `sum()`
