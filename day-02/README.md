# Day 2 - Python Development

## Objective

To learn Python fundamentals, file handling, exception handling,
and basic data analysis using Pandas.

## Python Exercises

The following Python concepts were practiced:

- Variables and data types
- Lists
- Tuples
- Sets
- Dictionaries
- Conditional statements
- Loops
- Functions
- Lambda functions
- List comprehensions
- Exception handling

File:

`python-exercises/basics.py`

## Employee Management System

A simple employee management system was developed using Python and JSON.

### Features

- Add employee
- Update employee
- Delete employee
- Search employee
- Filter employees by department
- Sort employees by salary
- Calculate employee statistics
- Store employee data in JSON
- Handle invalid input using exception handling

Files:

- `management-system/main.py`
- `management-system/employees.json`

## CSV Analysis

Employee data was analyzed using Pandas.

### Analysis Performed

- Count total records
- Check missing values
- Check duplicate records
- Calculate average salary
- Find minimum salary
- Find maximum salary
- Calculate department-wise salary statistics

Files:

- `csv-analysis/analyze.py`
- `csv-analysis/employees.csv`
