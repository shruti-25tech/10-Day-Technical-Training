\# Day 9 — Angular + TypeScript + API Integration



\## Objective



Build an Angular application and demonstrate REST API integration using TypeScript.

\* Facility inspection dashboard

\* Facility list

\* Inspection form using Reactive Forms

\* Inspection history

\* REST API integration

\* HTTP Client

\* RxJS Observable

\* Error handling

\* Angular routing

\* CSS

\* RxJS

\* REST API
