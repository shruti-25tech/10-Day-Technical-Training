# Day 5 - JavaScript and Employee Dashboard

## Objective

Learn modern JavaScript, asynchronous programming, APIs, and build an Employee Dashboard using reusable JavaScript functions.

## Topics Covered

### JavaScript Fundamentals

- let and const
- Data types
- Functions
- Arrow functions
- Arrays and objects
- Destructuring
- Spread and rest operators
- Template literals

### Array Methods

- map()
- filter()
- reduce()
- find()
- some()
- every()
- sort()

### Advanced JavaScript

- Scope
- Closures
- Hoisting
- Callbacks
- Promises
- async/await
- Event loop
- Modules
- Error handling

### APIs

- HTTP
- JSON
- Fetch API
- REST APIs
- GET
- POST
- PUT
- DELETE

## Employee Dashboard

The Employee Dashboard is a frontend application built using HTML, CSS and modern JavaScript.

### Features

- Display employee records
- Search employees
- Filter employees by department
- Sort employees by name and salary
- View employee details
- Add employees
- Edit employees
- Delete employees

## Technologies Used

- HTML
- CSS
- JavaScript
- JSON
- Fetch API
- Python HTTP Server
